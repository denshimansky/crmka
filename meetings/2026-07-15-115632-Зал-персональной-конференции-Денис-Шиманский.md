## Основные темы

### 1. Финансовый расчёт на август–сентябрь
Анна объясняет кассовый разрыв: выручка с 20-го числа пойдёт по новым тарифам, но зарплаты за июль будут выплачены в августе. Реальное сокращение расходов ожидается только в сентябре. Прогноз строится «по грязи» (до налогов), остаток после всех расходов — порядка 78 500 руб.

### 2. Перераспределение функций внутри команды: увольнение Оли и роль Насти
Принято решение расстаться с Олей. Обсуждались два варианта: полное увольнение сразу либо временное сохранение на сниженной ставке (10 000–17 000 руб.) для создания базы знаний в августе–сентябре. Настю планируют перевести на демонстрации и продажи — она знает продукт и способна проводить 3–4 демо в неделю.

### 3. Отключение сервера 1С и сохранение данных
Сервер 1С планируется выключить 1 августа. Обсуждался вопрос сохранения доступа к базе для Насти, чтобы она могла выгружать отчёты и данные без привлечения технической команды. Решено оставить минимальный сервер (порядка 10 000 руб./мес.) с доступом для одного пользователя на период августа.

### 4. База знаний для клиентов
Выявлена острая потребность в сайте-базе знаний с короткими видео, скринами и инструкциями. Текстовые гайды клиенты не читают. Задача создания базы рассматривается как временный проект для Оли в рамках переходного периода.

### 5. Автоматизация выставления счетов через API Тинькофф
Денис предложил подключить API Тинькофф, чтобы CRM автоматически выставляла счета и отслеживала их оплату. Также обсуждается необходимость кастомного шаблона счёта с договором-офертой вместо стандартного тинькоффского. Детали — на Диме.

## Ключевые решения

1. Новые тарифы вводятся с 20-го числа; август будет переходным месяцем с двойной нагрузкой по расходам.
2. Олю увольняют; рассматривается вариант временного сохранения до конца сентября на сниженной ставке (~10 000–17 000 руб.) с задачей создания базы знаний.
3. Настя выходит из отпуска и берёт на себя демонстрации и продажи начиная с 22-го числа.
4. Сервер 1С отключается 1 августа; на август оставляется урезанный инстанс (~10 000 руб.) с доступом для одного пользователя для Насти.
5. Пробный период для новых клиентов сокращается с 1 месяца до 2 недель.
6. Оплата в августе собирается по-старому (через счета), автоматизация через API Тинькофф — задача на следующий этап.
7. Личный кабинет для родителей (клиентов) — в разработке, стыковки ещё не завершены.

## Открытые вопросы

- **Финальное решение по Оле**: полное увольнение сразу или временное сохранение на сниженной ставке до конца сентября — не зафиксировано окончательно.
- **Выплаты Оле при увольнении**: Денис называет сумму 36 000 руб. на руки (47 000 с налогами), Анна предупреждает, что Оля будет детально считать все причитающиеся выплаты по законодательству — итоговая сумма может отличаться.
- **Тариф Димы на close**: текущий лимит в 200 ед. не хватает, вопрос увеличения остался без решения.
- **Срок запуска API Тинькофф**: в августе работают по-старому, дата перехода не определена.
- **Личный кабинет для родителей**: стыковки ещё не завершены, конкретных сроков не названо.
- **Яндекс.Метрика на базе знаний**: Денис предложил поставить счётчик, чтобы понять реальную посещаемость — решение не принято.

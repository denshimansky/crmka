# Пакетные абонементы в CRM «Умная Я»

Инструкция для сотрудников центра (владелец, управляющий, администратор)

---

## 1. Что такое пакетный абонемент и чем он отличается от месячного

В системе есть две рабочие модели абонементов, и центр выбирает одну из них для всей организации.

| | **Календарный (месячный)** | **Пакетный** |
|---|---|---|
| Логика | Каждый месяц — отдельный абонемент, привязанный к конкретному месяцу | «N занятий на срок M дней» |
| Когда ходит клиент | По расписанию своей группы в течение месяца | В любое доступное время в выбранной группе, пока не кончатся занятия или срок |
| Что списывается | Занятие месяца | Занятие из пакета |
| Срок | Календарный месяц | Срок годности в днях (например, 60 дней от даты начала) |
| Для кого | Детские центры с регулярным расписанием | Фитнес-студии, языковые школы, гибкое посещение |

Пакет описывается двумя числами: **сколько занятий** входит и **сколько дней действует срок годности**. Например: «8 занятий на 60 дней». Клиент приходит, когда ему удобно, каждое посещение «съедает» одно занятие из пакета. Когда занятия закончились или истёк срок — пакет закрывается.

Важное отличие: пакет **привязан к одной конкретной группе** (нельзя ходить в любые группы центра — только в выбранную при продаже).

## 2. Как включить пакетный тип

Тип абонемента — общий для всей организации и выбирается **один раз** при первичной настройке (в мастере онбординга на дашборде, шаг «Тип абонемента»).

**Шаги в мастере настройки:**

1. На шаге **«Тип абонемента»** показаны три карточки: «Календарный», «Пакетный» и «Фикс» (последняя недоступна — в разработке).
2. Выберите карточку **«Пакетный»** (подпись «Для фитнес-студий, школ языков»).
3. Появится поле **«Срок действия пакета по умолчанию (дней)»** — введите значение (по умолчанию 60). Его можно будет переопределить для каждого шаблона и для каждого конкретного абонемента.
4. Прочитайте красное предупреждение **«Тип абонемента нельзя сменить»** и нажмите «Далее».
5. Следующий шаг — **«Шаблоны пакетов»** (см. раздел 3), его можно пропустить и заполнить позже.

### Фиксация типа после первого абонемента

- Пока в системе **не создан ни один абонемент**, тип ещё не заблокирован.
- **Как только вы создадите (выпишете) первый абонемент** — даже неоплаченный, со статусом «Ожидание», — тип организации фиксируется автоматически и навсегда. Блокировка срабатывает в момент создания абонемента, а не в момент оплаты: достаточно выписать любой (в том числе тестовый) абонемент, и деньги при этом поступать не обязаны.
- После этого сменить модель работы самостоятельно нельзя — смена ломает отчёты, расчёт зарплаты инструкторов и биллинг.

> **Важно.** Не выписывайте «пробный» абонемент, чтобы «посмотреть, как работает», пока не уверены в выбранном типе: первый же созданный абонемент необратимо зафиксирует тип организации.

### Как сменить тип, если он уже зафиксирован

Разблокировать тип может **только техподдержка**. Напишите на **support@umnayacrm.ru**. Меняет тип только владелец.

Проверить текущий тип и статус блокировки можно в разделе **Настройки → Абонементы**. Там отображается текущий тип и, если он заблокирован, дата блокировки с обращением в поддержку. Сменить тип с этой страницы нельзя — она только показывает состояние.

## 3. Настройка шаблонов пакетов

Шаблон пакета — это готовая заготовка («столько-то занятий на столько-то дней»), которая появляется кнопкой в форме продажи и ускоряет работу администратора. Настраивать шаблоны могут только **владелец и управляющий**.

Настройки находятся в **Настройки → Абонементы** (блок виден только при пакетном типе).

### Общие настройки пакетов

Карточка **«Общие настройки пакетов»** содержит два поля:

| Поле | Что задаёт | Диапазон / по умолчанию |
|---|---|---|
| **Срок действия по умолчанию (дн.)** | Сколько дней действует пакет, если у шаблона и в форме срок не указан | 1–3650, по умолчанию 60 |
| **Уведомлять о скором истечении (дн. до)** | За сколько дней до окончания срока администраторы получат уведомление. `0` — уведомления выключены | 0–60, по умолчанию 7 |

После изменения нажмите **«Сохранить»**.

### Список шаблонов

Карточка **«Шаблоны пакетов»**:

1. Нажмите **«Добавить»** — появится новая строка.
2. В строке два поля: **«Занятий»** (1–1000) и **«Срок (дн)»** (1–3650). Поле срока можно оставить пустым — тогда возьмётся срок по умолчанию (в поле подсказка «по умолч. 60»).
3. Нажмите кнопку сохранения (иконка дискеты) в конце строки — она активна, только пока строка изменена.
4. Чтобы удалить шаблон — кнопка с корзиной.

**Типичный набор — 4 / 8 / 12 занятий.** В мастере онбординга эти три пресета предлагаются сразу.

Ограничения:
- Нельзя создать два активных шаблона с одинаковым числом занятий — система выдаст «Шаблон на N занятий уже существует».
- Удаление шаблона мягкое: уже проданные по нему абонементы сохраняются и продолжают работать.

## 4. Как продать пакет клиенту

Пакет выписывается из карточки клиента.

1. Откройте карточку клиента, нажмите кнопку **«Абонемент»** — откроется окно **«Новый абонемент»**.
2. Заполните обязательные поля: **Филиал**, **Направление**, **Группа** (при выборе направления цена занятия подставится из прайса). При наличии подопечных — выберите ребёнка.
3. В блоке пакета:
   - **Шаблон пакета** — нажмите на нужную плитку (на ней написано, например, «8 занятий» и «60 дн.»). Выбор шаблона автоматически подставит количество занятий и срок. Повторный клик по плитке снимает выбор — тогда вводите вручную.
   - **Дата начала** — по умолчанию сегодня.
   - **Срок (дн.)** — можно переопределить срок годности для этого конкретного пакета.
   - Строка **«Истекает: …»** показывает расчётную дату окончания (дата начала + срок).
4. Внизу — **Цена занятия** и **Занятий**. Итог считается автоматически: «Стоимость без скидки», строка скидки (если есть) и «Итого».
5. Сохраните.

Что важно знать про созданный пакет:
- Пакет создаётся со статусом **«Ожидание»** (не оплачен). Активным он становится после полной оплаты.
- **Уже в этот момент тип организации блокируется** (см. раздел 2) — если это первый абонемент в системе.
- Оплата проводится через **«Оплатить с баланса»** в карточке клиента: сумма списывается с баланса родителя, при полной оплате пакет переходит в «Активен».
- Продать пакет можно и без шаблона — просто ввести количество занятий, цену и срок вручную.
- Для пакетов не действует проверка на «дубликат за период» (в отличие от месячных), поэтому один клиент может иметь несколько пакетов одновременно.

### Скидки на пакет

- Автоматическая **скидка «за второй абонемент» на пакеты не распространяется** — пакеты в ней не участвуют.
- **Постоянная скидка клиента** (заданная в карточке родителя) на пакет **действует** — она уменьшает цену каждого занятия.

## 5. Отметка посещений: как «тают» занятия

### Как списывается занятие

Когда администратор отмечает посещение через **сетку «Посещения»** (массовая отметка группы), система сама находит подходящий пакет клиента в этой группе и списывает одно занятие по цене занятия.

**Правило подбора (FIFO — «первым пришёл, первым списался»):** если у клиента несколько пакетов, занятие списывается с **самого старого действующего** пакета — того, который начался раньше и ещё не истёк.

Через сетку «Посещения» пакет годится для автоподбора, только если одновременно:
- дата начала пакета уже наступила;
- срок годности не истёк (день истечения ещё считается действующим);
- **в пакете остались несгоревшие занятия** (остаток занятий больше нуля — независимо от того, оплачен пакет полностью или нет);
- статус «Активен» или «Ожидание».

> **Полностью оплаченный пакет списывается корректно.** Автоподбор выбирает пакет по **остатку занятий** (сколько занятий ещё не сгорело), а не по остатку к оплате. Поэтому полностью оплаченный (закрытый по деньгам) пакет с невыгоревшими занятиями находится и списывается и через сетку «Посещения», и через карточку занятия. Раньше такой пакет через сетку не находился и визит уходил в «разовое» — теперь это исправлено.

### Оба способа отметки выбирают пакет одинаково

И сетка «Посещения», и карточка занятия (а также «Отметить всех») выбирают пакет к списанию по одному правилу — **самый старый действующий пакет с остатком занятий** (FIFO). Полностью оплаченный пакет при этом списывается в обоих случаях. Разница только в удобстве: сетка отмечает всю группу за месяц сразу, карточка занятия — по одному занятию.

Пакет не подойдёт для списания (и там, и там), если занятия закончились, срок истёк или пакета в этой группе у клиента нет — тогда визит проведётся как разовое (см. ниже).

### Какие отметки расходуют занятие пакета

| Отметка | Расходует занятие пакета |
|---|---|
| **Был** | Да |
| **Прогул** | Да |
| **Не был** | Нет |
| **Уважительный пропуск** | **Нет** |
| **Перерасчёт** | Нет |
| Назначена отработка / Отработка | Нет |

Ключевое отличие от месячной модели: **у пакета уважительный пропуск занятие не сжигает** — оно сохраняется клиенту. (В календарной модели уважительный пропуск слот забирает.)

### Остаток занятий

Остаток виден в карточке клиента, вкладка **«Абонементы»**:
- столбец **«Отработано»** — сколько занятий использовано из общего числа (например, «3 / 8»);
- столбец **«Остаток»** — сколько занятий осталось (штук).

Это именно **количество занятий**, а не деньги.

### Что если занятия закончились, пакет истёк или его нет

Если на момент отметки система не нашла подходящего пакета — потому что все занятия **закончились** (остаток 0), срок **истёк**, или пакета в этой группе у клиента **нет вовсе**, — она **не выдаёт ошибку**. Посещение проводится как **разовое**: списывается стоимость разового посещения (или цена занятия направления) **с баланса родителя**. Баланс при этом может уйти в минус — это станет долгом, который виден в «Должниках». Занятие пакета в этом случае не тратится.

Поэтому вовремя продавайте новый пакет — см. раздел 7.

## 6. Срок годности: истечение, уведомления, продление

### Истечение и сгорание остатка

- Пакет действует **по дату истечения включительно**.
- На следующий день после истечения система автоматически (ежедневная фоновая проверка) закрывает пакет: статус становится «Закрыт».
- **Неиспользованные занятия сгорают** — деньги за них клиенту не возвращаются автоматически. Это осознанное бизнес-решение (остаток остаётся у организации). Вернуть деньги можно только вручную отдельной операцией.

### Уведомления о скором истечении

- Каждый день система проверяет пакеты, у которых срок истекает в ближайшие N дней (N — из настройки «Уведомлять о скором истечении», по умолчанию 7) **и остались несгоревшие занятия**.
- Приходит **уведомление в колокольчик** владельцу, управляющему и администраторам, а также ставится **задача администратору филиала** (срок задачи — дата сгорания пакета, привязка к клиенту).
- Текст: **«Истекает пакет: Фамилия Имя»**, в подробностях — направление, дата истечения и **остаток занятий** («осталось N занятий»).
- Уведомление и задача формируются по всем пакетам с несгоревшими занятиями — **в том числе по полностью оплаченным** (именно у них занятия рискуют сгореть без напоминания).
- Клик по уведомлению открывает карточку клиента.
- Если настройка выставлена в `0` — напоминания отключены.

### Ручное продление и реактивация

Продлить срок можно в карточке клиента, вкладка «Абонементы» — у пакетных абонементов есть кнопка **«Продлить срок пакета»** (иконка календаря):

1. Откроется окно **«Продление пакета»** с текущей датой истечения.
2. Укажите новую дату или воспользуйтесь быстрыми кнопками **«+7 дн» / «+14 дн» / «+30 дн»**.
3. Нажмите «Продлить».

Особенности:
- Если пакет уже **закрыт по истечении**, а новая дата — в будущем, при продлении он **снова станет активным** (появится подсказка об этом), и ребёнок вернётся в состав группы.
- Сгоревший ранее остаток при реактивации сохраняется — пакет снова доступен для списания занятий.

## 7. Продление и повторная продажа

**Автоматического продления пакетов нет.** Массовая выписка «на следующий период» работает только для календарных абонементов — пакеты в ней не участвуют.

Когда у клиента заканчиваются занятия или срок, вы:
- **либо продлеваете срок** текущего пакета (если занятия ещё остались, а истёк только срок) — см. раздел 6;
- **либо продаёте новый пакет** обычным способом через кнопку «Абонемент» (см. раздел 4).

Ориентируйтесь на уведомления в колокольчике и на столбец «Остаток» в карточке клиента.

## 8. Что видит клиент в личном кабинете

В личном кабинете родителя по каждому активному пакету подопечного отображается:
- **Срок** — «действует до ДД.ММ.ГГГГ»;
- **Остаток занятий** — «осталось X из N»;
- **Статус** — «Активен» или «Ожидает оплаты»;
- **Стоимость** и сумма «К оплате» (или отметка «Оплачен»).

После того как пакет закрывается по истечении, он пропадает из списка активных абонементов в кабинете родителя. Отдельного текста «пакет истекает через N дней» родителю не показывается.

## 9. Частые вопросы

**Можно ли в одном центре одновременно вести и месячные, и пакетные абонементы?**
Нет. Тип абонемента — один на всю организацию, выбирается один раз и фиксируется после создания первого абонемента (даже неоплаченного).

**Я выбрал не тот тип. Как исправить?**
Если ещё **не создан ни один абонемент** и онбординг **не завершён** — можно вернуться в мастер настройки и переключить тип там. Если онбординг уже завершён (даже если абонементов ещё нет) — переключить самостоятельно нельзя, страница «Настройки → Абонементы» работает только на просмотр. Если абонемент уже создан — тип заблокирован. В обоих случаях смена типа — только через техподдержку: support@umnayacrm.ru (меняет владелец).

**Клиент не ходил по уважительной причине. Сгорит ли занятие?**
Нет. У пакетов уважительный пропуск занятие не расходует — оно остаётся клиенту. Списывают занятие только отметки «Был» и «Прогул».

**У клиента остались занятия, но кончился срок. Что делать?**
Продлите срок пакета кнопкой «Продлить срок пакета» в карточке клиента (быстрые кнопки +7/+14/+30 дней). Занятия при этом снова станут доступны.

**Занятия у клиента кончились, а он пришёл на занятие. Что произойдёт при отметке?**
Посещение проведётся как разовое и спишется с баланса родителя (баланс может уйти в минус). Занятие пакета не потратится. Продайте клиенту новый пакет.

**Клиент оплатил пакет полностью — спишется ли занятие при отметке через сетку «Посещения»?**
Да. Автоподбор выбирает пакет по остатку **занятий**, а не по остатку к оплате, поэтому полностью оплаченный пакет находится и списывается и через сетку, и через карточку занятия. (Раньше такой пакет через сетку не находился и визит уходил в «разовое» — это исправлено.)

**Возвращаются ли деньги за несгоревшие занятия при истечении срока?**
Нет, автоматически неиспользованные занятия сгорают. Вернуть можно только вручную отдельной операцией.

**Действуют ли скидки на пакеты?**
Постоянная скидка клиента (из карточки родителя) на пакет действует. Автоматическая скидка «за второй абонемент» на пакеты не распространяется.

**Может ли клиент ходить в любую группу центра по пакету?**
Нет. Пакет привязан к одной группе, выбранной при продаже. Клиент посещает её в любое удобное время, пока есть занятия и не истёк срок.

**Придёт ли напоминание об истечении по полностью оплаченному пакету?**
Да. Напоминание в колокольчике и задача администратору формируются по всем пакетам с несгоревшими занятиями, включая полностью оплаченные. Дополнительно остаток можно смотреть в столбце «Остаток» карточки клиента.

**Где посмотреть, сколько занятий осталось у клиента?**
В карточке клиента, вкладка «Абонементы»: столбец «Отработано» (использовано из общего числа) и столбец «Остаток» (сколько занятий осталось). Родитель видит остаток и срок в своём личном кабинете.

## 10. Особенности отчётов для пакетной модели

Финансовый результат для пакетов считается корректно: **выручка и P&L считаются по фактически проведённым занятиям** (как и для месячных абонементов). А вот часть «месячных» отчётов рассчитана на календарную модель, поэтому для пакетов ведёт себя иначе — учитывайте это.

**Что работает корректно для пакетов:**
- **«Должники»** — показывают текущий остаток по всем неотчисленным абонементам независимо от типа (эта страница не привязана к месяцу и для пакетов работает «сама собой»).
- **«Ожидаемые поступления»** — учитывают пакеты по сроку их действия.
- **«Непродлённые» (в разрезе API/карточки клиента)** и виджеты дашборда по ожидаемым поступлениям.

**Что для пакетной организации может быть пустым или неполным** (эти отчёты рассчитаны на календарный месяц и пакеты в них не попадают):
- «Остатки оплаченных занятий»;
- «Отработанные абонементы»;
- «Расчёты с учениками»;
- «Абонементы по инструкторам»;
- «Прогноз прибыли»;
- «Отток по направлениям»;
- страница «Непродлённые абонементы».

Если такой отчёт показывает пусто — это ограничение для пакетной модели, а не отсутствие данных.

**Отдельно про отчёты оттока.** Когда пакет просто **заканчивается по сроку и не продлевается**, он закрывается со статусом «Закрыт», а не «Отчислен». Поэтому в отчётах оттока («Детализация оттока», «Отток по инструкторам», «Отток по месяцам») такие «естественно ушедшие» пакетные клиенты **не видны** — туда попадают только те, кого **явно отчислили**. Чтобы отслеживать клиентов с закончившимися и непроданными заново пакетами, ориентируйтесь на остаток занятий, срок действия и уведомления об истечении.

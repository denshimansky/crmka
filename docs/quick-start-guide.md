# Быстрый старт CRMka — главное для запуска центра

Короткая шпаргалка для владельца детского центра на первый день работы. Подробная версия — раздел **«Справка»** в самом приложении (пункт в меню слева) или файл `docs/getting-started-guide.md`. На каждой странице системы есть значок **«?»** — это встроенная подсказка по этой странице.

---

## Минимум, без которого не начать

Чтобы система заработала, нужны всего три вещи:

1. **Тип абонемента** — для детского центра выберите **«Календарный»**.
2. **Хотя бы 1 филиал с 1 залом (кабинетом)** — иначе некуда ставить занятия.
3. **Хотя бы 1 касса** — иначе нельзя принять оплату.

⚠️ Важно: тип абонемента нельзя сменить после первой продажи абонемента — определитесь сразу (для ДЦ почти всегда «Календарный»).

---

## Порядок настройки

При первом входе под владельцем откроется **мастер настройки** — пройдите его по шагам, не пропуская. Полная последовательность:

1. **Организация** — название, юрлицо, ИНН (для счетов).
2. **Филиалы и залы** — адрес, время работы (на старте оставьте широкое 08:00–21:00), кабинеты.
3. **Направления** — услуги центра. ⚠️ Указывайте цену за **одно занятие**, а не за месяц — из неё считаются абонементы, выручка и зарплата.
4. **Сотрудники** — логин латиницей + пароль (создаёте вы). Администратору обязательно отметьте **хотя бы один филиал**.
5. **Ставки ЗП инструкторам** — иначе их зарплата посчитается нулём.
6. **Параметры системы** — оплата прогула/пробных, дни выплат ЗП, лимит долга.
7. **Справочники** — причины отчисления, причины пропусков, каналы привлечения, виды посещений, сегментация.
8. **Касса** — заведите счета (наличные, эквайринг, расчётный).
9. **Производственный календарь** — внесите праздники **до** создания групп.
10. **Группы и расписание** — занятия сгенерируются автоматически с учётом праздников.
11. **Импорт базы из 1С** (если переносите) — только под владельцем.

## Что включить / выключить / проверить

- **Тип абонемента** → Календарный.
- **Оплата за прогул** → обычно **Нет**.
- **Оплата пробных педагогу** → обычно **«Не платить»** (или «Только платные» / «Все пробные»).
- **Дни выплаты ЗП** → ваши реальные числа (аванс ≤ 28, зарплата ≤ 30).
- **Автозакрытие неоплаченных абонементов** → на старте **выключите** (включите 7–14 дней позже).
- **Права администратора** → выключите ему «финансовый результат» и «чужие зарплаты», ограничьте возвраты и удаление клиентов.
- **Виды посещений** → проверьте: «Прогул» **списывает** оплату, «Уважительный пропуск» — **нет**; педагог видит только «Был / Не был».
- **Сегментация** → задайте пороги, иначе все клиенты будут «Новый».
- **Статьи расходов** → проверьте «Тип затрат» (постоянный/переменный), иначе P&L по направлениям будет врать.

## 5 понятий, без которых легко запутаться

1. **Доходы ≠ Выручка.** Доходы (ДДС) — это пришедшие деньги. Выручка (ОПИУ) — стоимость **отработанных** занятий. Цифры на дашборде и в отчёте не обязаны совпадать — это нормально.
2. **Долг — на абонементе, деньги — на балансе клиента.** Баланс родителя — это его реальные деньги; долг живёт отдельно, на абонементе. Система не списывает долг с баланса автоматически.
3. **Лид → Клиент необратимо.** Родитель становится клиентом при первой оплате, обратно в лиды вернуть нельзя. Не «продавайте» абонемент в системе раньше, чем получили деньги.
4. **Отметка «Был» = деньги.** Она списывает занятие с абонемента и начисляет зарплату педагогу. Не отметили занятия — нет выручки и нет ЗП.
5. **Дубликаты ищутся только по телефону.** Второго родителя с тем же номером система не даст завести.

## Один рабочий день в системе

Клиенты («+ Клиент») → Продажи (заявка → пробное → ожидаем оплату) → Оплаты (первая оплата = клиент) → абонемент и зачисление в группу → Расписание / карточка занятия (отметка «Был» = списание + ЗП) → Должники (контроль долга) → Зарплата (расчёт и выплата) → ДДС (закрыть период).

Каждый день крутится середина (заявки, пробные, оплаты, посещения, должники), а раз в месяц добавляются расчёт зарплаты и закрытие периода.

## Мини-чеклист перед первым клиентом

- [ ] Заведены организация, ≥ 1 филиал с залом, направления с ценой за занятие.
- [ ] Заведён администратор (логин латиницей, ≥ 1 филиал), права проверены.
- [ ] Инструкторам заданы ставки ЗП.
- [ ] Тип абонемента = Календарный; параметры системы выставлены осознанно.
- [ ] Заполнены причины отчисления и пропусков, каналы, проверены виды посещений.
- [ ] Заведена хотя бы одна касса.
- [ ] Производственный календарь заполнен; группы и расписание созданы.
- [ ] (Если переносите) база из 1С импортирована и проверена.

Если все галочки стоят — можно принимать первого клиента.
